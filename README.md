# ☁️ 空岛求生 - 文字版生存冒险游戏

基于"空岛求生"小说题材，融合多部热门小说核心设定的生存冒险游戏。

## 🚀 快速开始

```bash
# 确保 Python 3.8+ 已安装
python3 --version

# 运行游戏
cd sky-island-survival
python3 main.py
```

> **注意**：请在支持 ANSI 颜色的终端中运行（Windows Terminal / macOS Terminal / Linux 各终端）以获得最佳视觉效果。

## 🎮 游戏内容

### 世界观
全球人类被传送至浮空群岛世界。你醒来时脚下只有 **3×3米** 的浮空石。
通过垂钓获取物资，探索其他空岛，击败守护者，逐步扩张领地，在灾厄潮中生存下去。

### 核心玩法

| 系统 | 说明 | 来源小说 |
|------|------|---------|
| 🎣 **垂钓系统** | 甩竿垂钓获取宝箱，7级宝箱品质 | 《全民空岛求生》《垂钓求生》 |
| 🏝️ **岛屿扩张** | 融合其他空岛扩大领地，7级岛屿 | 《全球降临空岛》领地融合 |
| ⚠️ **灾厄潮** | 每7天一波怪物入侵，5种难度 | 各部小说共同设定 |
| 🌦️ **天气系统** | 6种天气 + 昼夜循环，影响生存 | 环境威胁机制 |
| 🔮 **天赋系统** | 开局三选一，81个天赋，10个等级 | 全系列小说经典天赋 |
| 🏆 **成就系统** | 16个成就，积分榜驱动 | 竞争与目标 |
| ⚔️ **回合制战斗** | 攻击/防御/物品/逃跑 | 战斗系统 |
| 🔧 **制作建造** | 工具/武器/装备/设施 | 生存建造 |

### 垂钓宝箱等级

| 等级 | 概率 | 内容 |

## 🏗️ 项目架构（面向2D转换）

```
sky-island-survival/
│
├── main.py                 ← 文字UI层（2D版替换此文件）

│   ├── events.py           ← 事件总线（UI通过事件获取游戏状态）

│   ├── explore.py          ← 探索系统（采集、事件、岛屿旅行）

│   ├── disaster.py         ← 灾厄潮系统（定期怪物入侵）

│   └── achievements.py     ← 成就系统
│
├── data/                   ← 数据文件（不修改，可独立扩展）
│   ├── items.json          ← 物品定义
│   ├── recipes.json        ← 配方定义
│   ├── creatures.json      ← 生物定义
│   ├── islands.json        ← 空岛定义
│   ├── events.json         ← 探索事件
│   ├── talents.json        ← 天赋库（81个天赋）
│   └── gameplay.json       ← 垂钓/宝箱/天气/灾厄/宠物数据
│
├── README.md               ← 本文件
├── DESIGN.md               ← 架构设计文档
└── DESIGN_GAMEPLAY.md      ← 玩法系统设计文档
```

### 转换为2D游戏的策略

```
文字版 (当前)              2D版 (未来)
┌─────────────┐           ┌─────────────┐
│   main.py   │  ─替换→   │ Godot场景   │
│  (文字UI)   │           │ (2D渲染)    │
├─────────────┤           ├─────────────┤
│  systems/   │  ─保留→   │  systems/   │
│  (游戏逻辑) │           │  (游戏逻辑) │
├─────────────┤           ├─────────────┤
│    core/    │  ─保留→   │    core/    │
│  (核心引擎) │           │  (核心引擎) │
├─────────────┤           ├─────────────┤
│    data/    │  ─保留→   │    data/    │
│  (JSON数据) │           │  (JSON数据) │
└─────────────┘           └─────────────┘
```

**核心原则**：所有游戏逻辑在 `core/` 和 `systems/` 中，零UI依赖。2D版只需实现新的UI层，监听相同事件，调用相同API。

```python
# 2D版示例（Godot + Python）
# 订阅事件显示伤害数字
event_bus.subscribe(EVT.COMBAT_HIT, show_damage_popup)

# 订阅事件播放音效
event_bus.subscribe(EVT.RESOURCE_GATHERED, play_gather_sound)

# 调用系统API处理点击
func on_gather_button_pressed(node_index):
    explore_system.gather_resource(node_index)
```

## 📊 数据驱动设计

所有游戏内容都在 `data/` 目录的 JSON 文件中：

| 文件 | 用途 | 扩展方式 |
|------|------|---------|
| `items.json` | 物品定义 | 添加新物品 |
| `recipes.json` | 制作配方 | 添加新配方 |
| `creatures.json` | 生物定义 | 添加新怪物 |
| `islands.json` | 空岛定义 | 添加新地图 |
| `events.json` | 探索事件 | 添加新事件 |
| `talents.json` | 天赋库 | 添加新天赋 |
| `gameplay.json` | 垂钓/天气/灾厄 | 调整数值平衡 |

**无需修改代码即可扩展游戏内容。**
